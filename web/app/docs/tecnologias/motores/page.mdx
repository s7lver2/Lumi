## Real-ESRGAN x4

<Ficha id="real-esrgan" ruta="registros/motores/real-esrgan.json" />

Un upscalador: reescala una imagen antes de que el resto del pipeline la toque, para que una foto
pequeña o comprimida no llegue con menos detalle del que un verificador necesita. Se invoca desde la
cola —{" "}
<Simbolo ruta="crates/lumid/src/queue/mod.rs">correr_upscale</Simbolo> — con un factor concreto (1×,
2×, 4×), no siempre a máxima resolución: reescalar cuesta tiempo de GPU, y una foto que ya llega
nítida no necesita el 4× completo.

## Dónde se usa

Real-ESRGAN se invoca bajo demanda, desde el editor de imagen del cliente, independientemente del
nivel.
